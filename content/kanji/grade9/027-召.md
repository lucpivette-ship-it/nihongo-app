# 召 — call, summon

**Strokes:** 5
**On-yomi (音読み):** shou
**Kun-yomi (訓読み):** me.su

## Example: On-yomi (shou)
- **JP:** 国会が召集された。
- **Reading:** こっかいがしょうしゅうされた。
- **EN:** The Diet (parliament) was convened.

## Example: Kun-yomi (me.su)
- **JP:** どうぞお召し上がりください。
- **Reading:** どうぞおめしあがりください。
- **EN:** Please help yourself (eat).
