# 幅 — hanging scroll, width

**Strokes:** 12
**On-yomi (音読み):** fuku
**Kun-yomi (訓読み):** haba

## Example: On-yomi (fuku)
- **JP:** 音を増幅させる装置です。
- **Reading:** おとをぞうふくさせるそうちです。
- **EN:** It's a device that amplifies sound.

## Example: Kun-yomi (haba)
- **JP:** この道の幅は狭いです。
- **Reading:** このみちのはばはせまいです。
- **EN:** This road's width is narrow.
