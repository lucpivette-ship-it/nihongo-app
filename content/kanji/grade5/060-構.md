# 構 — posture, stance, appearance, build, set up

**Strokes:** 14
**On-yomi (音読み):** kou
**Kun-yomi (訓読み):** kama.eru, kama.u

## Example: On-yomi (kou)
- **JP:** この建物の構造は複雑です。
- **Reading:** このたてもののこうぞうはふくざつです。
- **EN:** The structure of this building is complex.

## Example: Kun-yomi (kama.eru)
- **JP:** 剣を構えます。
- **Reading:** けんをかまえます。
- **EN:** I ready my sword.

## Example: Kun-yomi (kama.u)
- **JP:** 何を言われても構いません。
- **Reading:** なにをいわれてもかまいません。
- **EN:** I don't mind whatever is said.
