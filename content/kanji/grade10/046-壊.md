# 壊 — break, destroy

**Strokes:** 16
**On-yomi (音読み):** kai
**Kun-yomi (訓読み):** kowa.su, kowa.reru

## Example: On-yomi (kai)
- **JP:** 建物が破壊された。
- **Reading:** たてものがはかいされた。
- **EN:** The building was destroyed.

## Example: Kun-yomi (kowa.su)
- **JP:** 彼はおもちゃを壊した。
- **Reading:** かれはおもちゃをこわした。
- **EN:** He broke the toy.

## Example: Kun-yomi (kowa.reru)
- **JP:** このパソコンは壊れている。
- **Reading:** このパソコンはこわれている。
- **EN:** This computer is broken.
