# 値 — price, cost, value

**Strokes:** 10
**On-yomi (音読み):** chi
**Kun-yomi (訓読み):** ne, atai

## Example: On-yomi (chi)
- **JP:** この絵には価値があります。
- **Reading:** このえにはかちがあります。
- **EN:** This painting has value.

## Example: Kun-yomi (ne)
- **JP:** この商品の値段は高いです。
- **Reading:** このしょうひんのねだんはたかいです。
- **EN:** This product's price is high.

## Example: Kun-yomi (atai)
- **JP:** この値を確認してください。
- **Reading:** このあたいをかくにんしてください。
- **EN:** Please check this value.
