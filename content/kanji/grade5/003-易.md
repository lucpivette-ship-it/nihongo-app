# 易 — easy, ready to, simple, fortune-telling, divination

**Strokes:** 8
**On-yomi (音読み):** eki, i
**Kun-yomi (訓読み):** yasa.shii

## Example: On-yomi (eki)
- **JP:** 貿易の仕事をしています。
- **Reading:** ぼうえきのしごとをしています。
- **EN:** I work in trade.

## Example: On-yomi (i)
- **JP:** この作業は容易です。
- **Reading:** このさぎょうはよういです。
- **EN:** This task is easy.

## Example: Kun-yomi (yasa.shii)
- **JP:** この問題は易しいです。
- **Reading:** このもんだいはやさしいです。
- **EN:** This problem is easy.
