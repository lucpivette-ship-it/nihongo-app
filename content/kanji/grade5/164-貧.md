# 貧 — poverty, poor

**Strokes:** 11
**On-yomi (音読み):** hin, bin
**Kun-yomi (訓読み):** mazu.shii

## Example: On-yomi (hin)
- **JP:** 貧困問題について考えます。
- **Reading:** ひんこんもんだいについてかんがえます。
- **EN:** I think about the problem of poverty.

## Example: On-yomi (bin)
- **JP:** 彼は貧乏な学生でした。
- **Reading:** かれはびんぼうながくせいでした。
- **EN:** He was a poor student.

## Example: Kun-yomi (mazu.shii)
- **JP:** 貧しい家族を助けます。
- **Reading:** まずしいかぞくをたすけます。
- **EN:** We help poor families.
