# 蚕 — silkworm

**Strokes:** 10
**On-yomi (音読み):** san
**Kun-yomi (訓読み):** kaiko

## Example: Kun-yomi (kaiko)
- **JP:** 蚕を育てています。
- **Reading:** かいこをそだてています。
- **EN:** I'm raising silkworms.

## Example: On-yomi (san)
- **JP:** 養蚕業が盛んな地域です。
- **Reading:** ようさんぎょうがさかんなちいきです。
- **EN:** This is a region where silk farming thrives.
