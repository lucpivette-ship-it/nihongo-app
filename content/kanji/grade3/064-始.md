# 始 — begin

**Strokes:** 8
**On-yomi (音読み):** shi
**Kun-yomi (訓読み):** haji-meru, haji-maru

## Example: On-yomi (shi)
- **JP:** 会議が開始します。
- **Reading:** かいぎがかいししします。
- **EN:** The meeting commences.

## Example: Kun-yomi (haji-meru)
- **JP:** 勉強を始めます。
- **Reading:** べんきょうをはじめます。
- **EN:** I start studying.

## Example: Kun-yomi (haji-maru)
- **JP:** 授業が始まります。
- **Reading:** じゅぎょうがはじまります。
- **EN:** Class begins.
