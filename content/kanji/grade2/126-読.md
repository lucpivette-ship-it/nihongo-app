# 読 — read

**Strokes:** 14
**On-yomi (音読み):** doku, tou
**Kun-yomi (訓読み):** yo-mu

## Example: On-yomi (doku)
- **JP:** 読書が好きです。
- **Reading:** どくしょがすきです。
- **EN:** I like reading.

## Example: On-yomi (tou)
- **JP:** 文に読点を入れます。
- **Reading:** ぶんにとうてんをいれます。
- **EN:** I add a comma to the sentence.

## Example: Kun-yomi (yo-mu)
- **JP:** 本を読みます。
- **Reading:** ほんをよみます。
- **EN:** I read a book.
