# 駆 — drive, run

**Strokes:** 14
**On-yomi (音読み):** ク
**Kun-yomi (訓読み):** か.ける, か.る

## Example: On-yomi (ク)
- **JP:** 害虫を駆除した。
- **Reading:** くじょ
- **EN:** We exterminated the pests.

## Example: Kun-yomi (か.ける)
- **JP:** 子供たちは校庭を駆けた。
- **Reading:** かけた
- **EN:** The children dashed across the schoolyard.

## Example: Kun-yomi (か.る)
- **JP:** 不安が彼を駆り立てた。
- **Reading:** かりたてた
- **EN:** Anxiety spurred him on.
