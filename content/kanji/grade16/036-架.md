# 架 — construct, erect

**Strokes:** 9
**On-yomi (音読み):** カ
**Kun-yomi (訓読み):** か.かる, か.ける

## Example: On-yomi (カ)
- **JP:** この駅の近くには高架線が通っている。
- **Reading:** このえきのちかくにはこうかせんがとおっている。
- **EN:** There is an elevated line running near this station.

## Example: Kun-yomi (か.かる)
- **JP:** 川に橋が架かっている。
- **Reading:** かわにはしがかかっている。
- **EN:** A bridge spans the river.

## Example: Kun-yomi (か.ける)
- **JP:** 川に新しい橋を架けた。
- **Reading:** かわにあたらしいはしをかけた。
- **EN:** We built a new bridge across the river.
