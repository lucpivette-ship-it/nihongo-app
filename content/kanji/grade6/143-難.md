# 難 — difficult, impossible, trouble, accident, defect

**Strokes:** 18
**On-yomi (音読み):** nan
**Kun-yomi (訓読み):** kata.i, muzuka.shii

## Example: Kun-yomi (muzuka.shii)
- **JP:** この問題は難しいです。
- **Reading:** このもんだいはむずかしいです。
- **EN:** This problem is difficult.

## Example: On-yomi (nan)
- **JP:** 困難を克服しました。
- **Reading:** こんなんをこくふくしました。
- **EN:** I overcame the difficulty.

## Example: Kun-yomi (kata.i)
- **JP:** それは信じ難いことです。
- **Reading:** それはしんじがたいことです。
- **EN:** That's hard to believe.
