# 組 — group,組む

**Strokes:** 11
**On-yomi (音読み):** so
**Kun-yomi (訓読み):** ku-mu, kumi

## Example: On-yomi (so)
- **JP:** 組織を作ります。
- **Reading:** そしきをつくります。
- **EN:** We create an organization.

## Example: Kun-yomi (ku-mu)
- **JP:** チームを組みます。
- **Reading:** チームをくみます。
- **EN:** I form a team.

## Example: Kun-yomi (kumi)
- **JP:** クラスで組を作ります。
- **Reading:** くらすでくみをつくります。
- **EN:** We make groups in class.
